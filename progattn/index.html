Training Transformers with Programmatic Attention Fails Without Routing-Carrying Programs

Gene Yang · 31 August 2026 · the brief version — full report

We investigate whether initializing a fresh transformer with the programmatic attention patterns synthesized in Hayes et al.1 confers the convergence speedup that exact attention patterns from a trained GPT-2 do, and if so, what predicts it. Although initializing with programs converges faster than random initialization, we find that the programmatic attention patterns themselves are much less impactful: programs speed up training no more than the same programs shuffled onto the wrong documents, and replacing a head with its program changes the trained model's held-out cross-entropy, on average, as much as deleting the head.

Motivation and Commentary

It's known that injecting attention patterns from a trained model accelerates convergence2. Hayes et al.1 synthesize Python programs that “reproduce those attention maps given only input text”: if the programs capture what the heads do, their patterns should accelerate convergence too. 

Let exact be the method where the model is initialized with the exact attention patterns the trained model has on each document, while program is the method that matches each head with the best fitting pattern. We already know that exact should help, so the question becomes how program performs: if it beats exact, the fit is denoising the learned circuit into a better prior, and if it loses most of the benefit, the approximation dropped something that matters for learning.

The rest of this describes my findings from training GPT-2-style models with various attention pattern initializations. I first found a large speedup for exact and a modest one for programmatic. My goal was then to identify what predicted the training speedup that an attention head (programmatic or real) would confer.

For real heads there are predictors: the benefit rises with depth and with "input dependence", or how much the head's attention moves with the text (ρ = +0.25 over all 144 heads). For programs everything failed. IoU predicted nothing, and sparsity, which did predict program speedup on sink-free heads (ρ = −0.52), turned out to price any sparse pattern rather than these programs: an entropy-matched wrong program did just as well. So the programs' benefit was predictable only from generic properties of the pattern, never from anything tying a program to its head.

Main result

Exact attention transfers and boosts training, while programs barely do so. Re-pairing patterns with the wrong documents collapses exact's speedup and leaves program runs unmoved. Programs match the heads' sparsity (mean row entropy 1.76 against 1.81), so no property of the patterns themselves explains the gap; the benefit rides on the pairing.

Why exact gives speedups while program doesn't

Any stable prior helps?

Causal-uniform is a fixed, valid attention prior injected identically. It buys +0.01% over all 144 heads and −0.9% at K = 16, so the programs' small edge must come from what they specifically contain.

The fit discards the input-dependence that matters?

The paper re-ranks candidate programs by document-averaged IoU, which favors flat programs: the chosen fits average 0.049 input-dependence against the library's 0.161, 8.9 SD below a random pick. But giving every head the program synthesized from its own attention — 3.3× the input-dependence of the best fit — converges the same (+0.42% against +0.34%, p = 0.41) and is equally indifferent to shuffling. More input-dependence in the program does not put routing back.

The fixed rule freezes the circuits programs need?

Under bias injection the QK circuits keep their gradients and each head learns a weight λ on its prior. The ordering reproduces (exact +3.90%, own program +0.67%, best-fit +0.30%, uniform +0.05% over 144 heads), and heads amplify their program priors (λ = 1.05–1.17) while gaining nothing from them: the programs are used, and still don't help.

The pruning effect, causal

If programs carry no routing, why does splicing one into a trained model preserve it at all? The paper flags that its replacement gains “may be akin to a pruning effect.” We find that they are: a program preserves the trained model on average as well as deleting the head, and the head's own mean pattern does slightly better with no program at all.

How much routing buys the speedup back

The ladder's gentlest replacement was the head's own mean pattern — its shape with the routing removed. That template is one end of a dial: replace each head's pattern with λ·(its attention on the document) + (1−λ)·(its document-mean template) and train as before (16 heads, 3 seeds, one head per run).

The template alone matches the best-fit program (+1.51% against +1.35%, p = 0.22) — the program floor reached with the head's own shape, no symbolic fit — and every dose of real routing is significant (each point over program at p ≤ 4×10−5). The curve is concave — the first quarter of the routing restores 47% of the program-to-exact gap — and the last quarter is still real (exact over λ = ¾ by +0.45 points, p = 3×10−4). The speedup is bought by routing, in proportion to the dose.

Open

We know that the paper's programs do not work in the ways we've tried, but nothing about what symbolic attention patterns could do in principle. We also have not evaluated on downstream abilities like QA. One thing worth running: an induction-style rule that genuinely tracks the text.
